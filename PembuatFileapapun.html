Mengonversi File

Ikuti langkah-langkah berikut untuk mengonversi file:

  1. Klik area unggah atau seret file ke area tersebut
  2. Pilih format tujuan dari opsi yang tersedia
  3. Klik tombol "Konversi File" untuk memulai proses
  4. Tunggu hingga proses selesai dan file akan diunduh otomatis

Mengonversi Teks

Ikuti langkah-langkah berikut untuk mengonversi teks:

  1. Ketik atau tempel teks ke dalam area teks
  2. Pilih format tujuan dari opsi yang tersedia
  3. Klik tombol "Konversi Teks" untuk memulai proses
  4. Tunggu hingga proses selesai dan file akan diunduh otomatis

Memindai dengan Kamera

Ikuti langkah-langkah berikut untuk memindai dokumen:

  1. Klik "Hidupkan Kamera" untuk mengaktifkan kamera
  2. Posisikan dokumen dalam bingkai kamera
  3. Sistem akan otomatis mendeteksi dan memindai dokumen
  4. Klik "Ambil Gambar" untuk menangkap gambar secara manual
  5. Pilih format tujuan dan klik "Konversi Gambar"
